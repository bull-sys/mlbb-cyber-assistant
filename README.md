# MLBB Cyber Assistant — PWA + backend

Готовый стартовый full-stack продукт: устанавливаемая PWA, сервер авторизации, база игроков, поиск тиммейтов, черновое лобби, драфт-анализ, контр-сборки, энциклопедия и необязательный AI-слой.

## Что действительно работает
- PWA: manifest, service worker, offline shell, установка на iPhone через Safari → «Поделиться» → «На экран Домой».
- Регистрация / вход по email и паролю, JWT, SQLite.
- Создание и редактирование анкеты, фильтры по роли/герою/стилю/рангу.
- Лайк профиля и взаимный матч, список матчей.
- Драфт: ручной выбор, тестовый драфт, загрузка скриншота и OCR в браузере (Tesseract.js CDN), список кандидатов на распознавание; пользователь подтверждает распознанных героев.
- Контр-сборка и энциклопедия с локальным справочником.
- AI-пояснение через OpenAI API, если задан `OPENAI_API_KEY`. Без ключа работает детерминированная эвристика.
- Базовые меры безопасности: bcrypt, JWT, Helmet, rate limit, валидация входных данных, ограничение размера загрузки.

## Важно про актуальность MLBB
Это независимый фанатский помощник, не продукт Moonton и не подключён к внутреннему API игры. В репозитории есть стартовый набор справочных данных и эвристики, а не подтверждённая live-мета. Патчи, названия, характеристики, таланты и доступность предметов меняются. Перед соревновательным использованием сверяйте данные с текущим клиентом игры. Не выдавайте локальные эвристики за win-rate или статистику матчей.

## Запуск локально
Требуется Node.js 22.x.
1. Распакуйте архив.
2. Скопируйте `.env.example` в `.env`, задайте уникальный `JWT_SECRET`.
3. Выполните:
   ```bash
   npm install
   npm start
   ```
4. Откройте `http://localhost:3000`.

Для AI-пояснений добавьте `OPENAI_API_KEY` в `.env`. Ключ хранится только на сервере — не вставляйте его в frontend.

## Тесты
Используйте Node.js 22, затем установите зависимости и запустите тесты:
```bash
npm install
npm test
```
HTTP-тесты запускают сервер во временной копии и подключают установленную папку `node_modules` проекта. Установка зависимостей требуется до запуска тестов; `dotenv` уже указан в `package.json`.

В репозитории пока нет lockfile, поэтому `npm install` может выбрать разные версии зависимостей в пределах заданных диапазонов. Для воспроизводимой установки минимальное решение — добавить созданный npm файл `package-lock.json` в репозиторий и затем использовать `npm ci`.

## Публикация в интернете
PWA требует HTTPS (кроме localhost). Самый простой вариант — VPS с Docker:
1. Установите Docker и Docker Compose.
2. Загрузите проект на сервер.
3. Создайте `.env` из примера и задайте `APP_URL=https://ваш-домен`, `JWT_SECRET`, при желании `OPENAI_API_KEY`.
4. Настройте HTTPS reverse proxy (например, Caddy или Nginx + Let's Encrypt).
5. `docker compose up -d --build`.
6. Проверьте `https://ваш-домен/api/health`.

Не публикуйте `.env`, SQLite-файл или папку uploads. Для production настройте резервное копирование `data/`, мониторинг, SMTP/проверку email и политику хранения данных.

## Установка на iPhone
Откройте опубликованный HTTPS-адрес в Safari → кнопка «Поделиться» → «На экран Домой» → включите «Открывать как веб-приложение», если пункт доступен.

## Архитектура
- `public/` — PWA UI, manifest, service worker, иконки.
- `server/index.js` — REST API, auth, matchmaking, AI endpoint.
- `server/data.js` — предметы, таланты, герои и правила.
- `data/` — SQLite база (создаётся автоматически).

## Ограничения и следующие production-шаги
- OCR делается на устройстве через CDN Tesseract.js и требует интернета для загрузки библиотеки/языковых данных при первом запуске.
- Реальный поиск работает среди зарегистрированных пользователей этого развёртывания; ботам и тестовым карточкам места нет.
- Нет чата, push-уведомлений, подтверждения email, сброса пароля, антифрода и модераторской панели. Это необходимые следующие этапы перед большим публичным запуском.
- Интеграции с официальной статистикой/публичной базой MLBB не добавлены: используйте только разрешённые источники и проверяйте условия API.
